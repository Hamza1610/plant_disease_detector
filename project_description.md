# Omnivax: Enterprise Plant Disease Intelligence Platform

**Role:** AI & Full-Stack Engineer
**Domain:** Agritech, Machine Learning, System Architecture

## Executive Summary
Architected and deployed **Omnivax**, a highly scalable, Model-as-a-Service (MaaS) AI platform designed to perform high-speed agronomic diagnostics. The platform natively decouples the visual inference layer (Computer Vision) from the reasoning layer (Conversational LLM), enabling real-time detection of plant pathologies and providing contextual, actionable remediation strategies.

## The Problem
Traditional agronomic diagnostic tools and ML pipelines are fundamentally limited; they typically conclude at a static categorical classification (e.g., "Tomato Early Blight") without providing actionable, sequential reasoning. Furthermore, monolithic architectures in this space suffer from cold-engine latency, rigid input requirements (static images only), and a lack of scalable API infrastructure for enterprise or third-party developer integration.

## The Solution
Engineered a decoupled microservice ecosystem that bridges the gap between raw visual tensor output and human-readable, conversational intelligence. Omnivax utilizes an agnostic, multi-framework inference architecture (supporting PyTorch, TensorFlow, and Scikit-Learn backends) as the primary visual telemetry parser. The system seamlessly funnels predictive distributions into a continuous logic loop evaluated by a Large Language Model (LLM), establishing an "AI Agronomist" capable of real-time diagnostics via web-cam optical flow and persistent memory conversations.

## Architecture & Design Concepts
*   **Decoupled Microservice Architecture:** Strict separation between the Next.js presentation layer, FastAPI middleware/routing layer, and multi-framework inference adapter engines.
*   **Live Optical Flow & Real-Time Telemetry:** Bypassed traditional static upload constraints by implementing WebRTC media stream hijacking. The frontend systematically extracts DOM canvas frames at rigid interval thresholds and transmits them to the backend tensor engine for continuous, real-time inference.
*   **Production-Ready Universal Adapter Engine:** Designed a unified ML backend to securely load and execute various production-ready model artifacts (PyTorch `.pth`, Keras `.h5`, Scikit-Learn `.pkl`) into memory at kernel startup. This prevents cold-engine latency on iterative client requests and supports seamless hot-swapping of classification algorithms, maximizing flexibility for end-users.
*   **Conversational Reasoning Subsystem:** Developed an advanced injection pipeline where visual probabilities generated by the CNN are natively serialized into the continuous context window of Gemini 2.5-Flash, establishing a stateful session loop without context loss.
*   **Identity & Access Management (IAM):** Built a dual-layer authentication system utilizing JWT (RS256) for web sessions and cryptographic SHA-256 hashed API keys for service-level CLI/automation access.

## Implementation Strategy
1.  **AI/ML Pipeline:** Engineered a robust, multi-backend inference pipeline integrating an **EfficientNet-B0** (PyTorch) foundation alongside adapters for **TensorFlow/Keras** and **Scikit-Learn** models. Enforced strict dimensional standardizations and developed a `ModelRegistry` service to track versioning across all frameworks, telemetry, and experimental metrics (F1 statistics, P50/P95 latencies).
2.  **Backend Engineering:** Constructed an asynchronous API gateway utilizing **FastAPI** and **Python 3.12+**. Implemented robust data validation via Pydantic and managed database pooling with SQLAlchemy ORM connecting to a **PostgreSQL (Supabase)** persistence layer.
3.  **Frontend & UX:** Developed a responsive, glassmorphic client interface using **Next.js 14 (App Router)** and **TailwindCSS/Vanilla CSS**. Engineered complex React Hooks for state management, live data synchronization, and camera stream handling.
4.  **Developer Ecosystem:** Shipped a professional-grade CLI tool utilizing `typer` and `rich`, providing developers with secure, authenticated access to the platform's inference engines and model management infrastructure.

## Impact & Value Delivered
*   **Operational Efficiency:** Reduced diagnostic latency by implementing in-memory model state caching and asynchronous API routing.
*   **Enhanced User Experience:** Transformed a static diagnostic process into a dynamic, real-time AI consultation, significantly increasing the practical value of the agronomic data.
*   **Enterprise Readiness:** Delivered a production-ready, horizontally scalable platform complete with rigorous security protocols, developer API access, automated testing (`pytest`), and comprehensive CI/CD architectural planning.

## Technology Stack
*   **AI/Machine Learning:** PyTorch, TensorFlow, Keras, Scikit-Learn, Google Gemini 2.5-Flash LLM.
*   **Backend & API:** Python 3.12+, FastAPI, Uvicorn (ASGI), Pydantic, SQLAlchemy.
*   **Frontend UI:** Next.js 14+ (App Router), React Server Components, WebRTC.
*   **Database & Auth:** PostgreSQL, Supabase Auth (JWT), Bcrypt, custom SHA-256 Key Management.
*   **Tooling:** Pytest, Typer/Rich (CLI), Docker.
