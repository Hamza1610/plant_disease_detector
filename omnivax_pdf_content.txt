1. SYSTEM OVERVIEW
What the System Does (Based on Code Evidence)
Omnivax is a plant disease intelligence platform that provides:
•

A cloud-based API for running ML inference on plant/leaf images

•

A model registry for managing, discovering, and deploying computer vision models

•

Real-time prediction capabilities with confidence scoring

•

Benchmark tracking for model performance evaluation

•

Usage quota management with tiered pricing

•

AI-powered agronomic recommendations via Gemini integration

Core Purpose
Democratize access to high-performance computer vision systems for farmers, researchers, and ag-tech
startups by providing:
1. Pre-trained models for plant disease detection (corn, tomato)
2. Infrastructure for developers to upload and manage their own models
3. Multi-modal access (Web UI, CLI, REST API)
